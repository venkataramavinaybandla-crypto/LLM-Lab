# 290-Day Roadmap: AI/ML + Software Engineering Skills

This roadmap is designed for a beginner-to-intermediate learner targeting practical AI/ML engineering, while also building strong software and CS fundamentals.

## Structure at a glance

- Total duration: **290 days** (~9.5 months)
- Weekly effort target: **15–20 hours**
- Study split guideline:
  - 40% core learning (new topics)
  - 40% implementation/projects
  - 20% revision + problem-solving

---

## Phase 0 — Setup, Learning System, Baseline (Day 1–10)

### Goals
- Set up environment and study workflow.
- Build consistency habits before heavy content.

### Topics
- Tooling: Git, GitHub, VS Code, Linux basics, virtual environments.
- Study system: daily planning, note templates, spaced repetition.
- Python baseline check.

### Output
- One GitHub repo for this journey.
- Weekly tracker and learning journal.

---

## Phase 1 — Python + C++ (optional) + Java Basics + CS Core (Day 11–70)

### Goals
- Become comfortable writing clean code.
- Understand core CS building blocks.

### Topics
- **Python (primary)**: data types, loops, functions, OOP, modules, files, exceptions.
- **Java (secondary)**: syntax, OOP, collections, basic multithreading concept.
- **C++ (optional)**: syntax, STL, classes, pointers/references, memory basics.
- **Computer Science Fundamentals**:
  - OS basics (process, thread, memory, scheduling)
  - Networking basics (HTTP, TCP/IP, DNS)
  - DBMS basics (SQL, indexing, normalization)
  - Git branching and collaboration workflows

### Output
- 3 mini-projects:
  1. CLI task manager (Python)
  2. File analyzer/log parser (Python)
  3. OOP project (Java or C++)

---

## Phase 2 — DSA + Problem Solving + Maths Foundation (Day 71–130)

### Goals
- Build algorithmic thinking.
- Prepare math intuition for ML.

### Topics
- **DSA**:
  - Arrays, strings, linked list, stack, queue, hash map
  - Trees, heaps, graphs
  - Sorting/searching, recursion, dynamic programming, greedy
  - Time/space complexity and trade-offs
- **Maths for AI/ML**:
  - Linear algebra: vectors, matrices, eigenvalues/eigenvectors
  - Probability: distributions, Bayes rule, expectation, variance
  - Statistics: hypothesis testing, confidence intervals
  - Calculus: derivatives, gradients, chain rule, partial derivatives

### Output
- Solve ~200 DSA problems (easy/medium-heavy).
- Math notes with visual intuition examples.
- 1 project: "algorithm visualizer" or "complexity benchmark suite".

---

## Phase 3 — Data Handling, EDA, and Feature Engineering (Day 131–170)

### Goals
- Become strong in real-world data workflows.

### Topics
- Data handling with NumPy, Pandas.
- Data cleaning: missing values, outliers, duplicates.
- EDA and visualization: Matplotlib, Seaborn, Plotly.
- SQL for analytics: joins, group by, windows, CTEs.
- Feature engineering and preprocessing pipelines.

### Output
- 2 end-to-end notebooks (tabular and time-series).
- 1 dashboard/report with clear business insights.

---

## Phase 4 — Machine Learning Core (Day 171–210)

### Goals
- Learn supervised and unsupervised ML deeply.

### Topics
- Supervised learning: linear/logistic regression, trees, random forest, XGBoost.
- Unsupervised learning: k-means, PCA, clustering validation.
- Model evaluation: train/val/test, cross-validation, metrics (precision/recall/F1/AUC).
- Bias-variance, overfitting, regularization, hyperparameter tuning.

### Output
- 3 applied ML projects:
  1. Classification project
  2. Regression project
  3. Clustering/segmentation project

---

## Phase 5 — Deep Learning + NLP (Day 211–250)

### Goals
- Move from classical ML to neural models.
- Learn modern NLP pipeline patterns.

### Topics
- Deep learning basics: perceptron, MLP, backpropagation, optimizers.
- Framework: PyTorch (or TensorFlow/Keras).
- CNN basics for vision understanding.
- Sequence models: RNN/LSTM/GRU basics.
- NLP for AI:
  - Text preprocessing and tokenization
  - Word embeddings
  - Attention and Transformer intuition
  - Fine-tuning pretrained language models

### Output
- 2 deep learning projects.
- 1 NLP project (sentiment, QA, text classification, or summarization).

---

## Phase 6 — Backend + MLOps + Deployment + System Design (Day 251–280)

### Goals
- Ship models to production-style environments.

### Topics
- **Backend development**:
  - FastAPI (recommended), REST APIs, auth basics
  - Async basics, logging, validation
- **MLOps**:
  - Experiment tracking (MLflow/W&B)
  - Data and model versioning (DVC/Git-LFS)
  - Docker basics
  - CI/CD basics (GitHub Actions)
  - Monitoring concepts (drift, latency, failure)
- **System Design**:
  - Scalability basics (load balancer, cache, queue)
  - Design ML inference pipeline (batch + real-time)
  - Trade-offs: latency vs cost vs quality

### Output
- 1 production-style ML API project with Docker.
- 1 mini system design document for AI service architecture.

---

## Phase 7 — Capstone, Interview Prep, Portfolio Polish (Day 281–290)

### Goals
- Convert learning into visible proof of skill.

### Tasks
- Build one **capstone** combining:
  - data pipeline + ML/DL model + API + monitoring basics
- Finalize GitHub portfolio (clean READMEs, demos, architecture diagrams).
- Prepare resume bullets and interview stories.

### Output
- 1 capstone repository.
- 1 portfolio page with project links and outcomes.

---

## Weekly Routine Template (recommended)

- **Mon–Thu (2–3 hrs/day)**: Core learning + coding practice
- **Fri (2 hrs)**: Revision + summary notes
- **Sat (4–5 hrs)**: Project implementation
- **Sun (3–4 hrs)**: DSA/math + weekly review + planning

---

## Milestone Checks

- Day 70: Can build basic apps in Python/Java and explain CS basics.
- Day 130: Comfortable with DSA medium problems and core ML math.
- Day 170: Can perform complete EDA and preprocessing on messy datasets.
- Day 210: Can train/evaluate multiple ML models correctly.
- Day 250: Can build and fine-tune basic DL/NLP models.
- Day 280: Can deploy model APIs and explain system design choices.
- Day 290: Capstone complete and portfolio interview-ready.

---

## Recommended Project Themes

- Fraud detection
- Customer churn prediction
- Retail demand forecasting
- News/sentiment analysis
- Resume screening assistant
- FAQ/knowledge assistant with LLM + retrieval

---

## Priority Rules (important)

1. Python + math + DSA are non-negotiable.
2. Java/C++ are supportive skills; keep them secondary to Python.
3. Projects matter as much as courses.
4. Always document assumptions, metrics, and trade-offs.
5. Build publicly (GitHub) from day one.
