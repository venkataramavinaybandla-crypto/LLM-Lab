# LLM Lab

A personal experimentation space for working with Large Language Models (LLMs).

This repository is created to understand how LLMs behave in real usage —
not just how they perform in ideal demos.

---

## Why LLM Lab?

Most AI projects focus on outputs.
This lab focuses on **behavior**.

The idea is simple:
- Ask real questions
- Observe real responses
- Note real limitations

No hype. No shortcuts.

---

## What this repository contains

- Small experiments using LLM APIs
- Tests with free models via OpenRouter
- Notes on response quality, latency, and limits
- Incremental learning, not polished products

This is a lab, not a tutorial repository.

---

## Repository Scope

This repository is **strictly reserved for AI and LLM-related work**.

Things that belong here:
- LLM experiments
- Prompt testing
- Model comparisons
- AI system prototypes

Things that do NOT belong here:
- General Python practice
- DSA
- Non-AI projects

---

## Tools Used

- Python
- OpenRouter (free LLM models)
- Local LLMs (planned)
