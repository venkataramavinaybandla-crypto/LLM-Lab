## 📌 About

LLM-Lab is a hands-on playground where I test, break, and learn from LLMs. Each experiment explores one idea, such as prompting, model comparison or output behavior, using **OpenRouter**, **local models**, and **Python**.

## 🛠️ Tech Stack

- **Language:** Python
- **Model access:** [OpenRouter](https://openrouter.ai) API
- **Local inference:** local LLMs (e.g., Ollama)
- **Environment:** Jupyter / Google Colab / VS Code

## 🚀 Getting Started

```bash
# 1. Clone the repo
git clone https://github.com/venkataramavinaybandla-crypto/LLM-Lab.git
cd LLM-Lab

# 2. (Optional) Create a virtual environment
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Add your API key
export OPENROUTER_API_KEY="your_key_here"
```

> ⚠️ Never commit your API key. Use environment variables or a `.env` file listed in `.gitignore`.

## ▶️ Running an Experiment
